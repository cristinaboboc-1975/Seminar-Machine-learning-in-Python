## Instrucțiuni pentru studenți

1. Deschideți notebook-ul corespunzător folosind butonul **Open in Colab**.
2. Salvați o copie a notebook-ului în Google Drive sau în propriul cont GitHub.
3. Rezolvați problemele/exercițiile indicate în notebook.
4. Salvați notebook-ul după finalizarea rezolvărilor.
5. Încărcați pe GitHub varianta finală a notebook-ului cu rezolvările.

### Denumirea fișierelor

Pentru identificarea ușoară a lucrărilor, folosiți următoarea convenție:

`Nume_Prenume_LP1.ipynb`

Exemplu:

`Popescu_Andrei_LP1.ipynb`
